# Backend

This folder contains the backend portion of the group project.

## Backend Structure

- `config/` — database configuration
- `db/` — database/mock data handling
- `middleware/` — backend middleware such as authentication
- `models/` — data models
- `routes/` — API route modules
- `.env.example` — example environment configuration
- `package.json` — backend dependencies and scripts
- `server.js` — backend server entry point

## Main Route Modules

The current backend contains route modules for:

- Authentication
- Messages
- Tasks

> This documentation was added without modifying the existing backend source code.

## Important

Do not commit real credentials, API keys, passwords, or private environment variables. Use the provided `.env.example` as the template for local configuration.
