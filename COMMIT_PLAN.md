# Meaningful Commit Plan

Use this project to build a real contribution history.

## Good commit categories
- Documentation updates
- Small frontend improvements
- Component refactoring
- API validation
- Error handling
- Tests
- Accessibility
- Performance
- Dependency maintenance
- Deployment improvements

## Example weekly target
Aim for 3-10 meaningful commits while working on real improvements.

Avoid empty or artificial commits made only to increase contribution numbers.
