# 🎯 GET STARTED NOW

## 1️⃣ Run the App
```bash
npm run dev
```

## 2️⃣ Open Browser
Go to: `http://localhost:5173`

## 3️⃣ Login
- Username: `john_doe` (or any name)
- Click Login

## 4️⃣ You're on Dashboard
See Quick Actions at the bottom

## 5️⃣ Click "💬 Messages"
Opens full-screen chat page

## 6️⃣ Start Chatting

### Option A: Team Chat
- Messages everyone can see
- Type → Send
- Done!

### Option B: Direct Messages
- Click a person's name on left
- Type message → Send
- Private 1-on-1

## 7️⃣ Done!
You now have a fully working messaging system.
